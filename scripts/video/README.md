# Vidéo de présentation

1. `capture.js` : captures de la pharmacie démo sur werguisn.pages.dev (Playwright).
2. `video.py` : commentaire (voix IA Piper, voix française « siwis » ou « tom »), sous-titres et diapositives HTML.
3. `slides.js` : rendu des diapositives en images 1920×1080.
4. `montage.py` : montage (zoom, fondus, voix, sous-titres) avec ffmpeg.

Les vidéos produites sont rangées dans `marketing/` (non publié).
